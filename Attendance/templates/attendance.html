How Attendance Works

  1. Click Start: Click the "Start Face Recognition" button
  2. Camera Opens: System activates your webcam
  3. Face Detection: System detects faces in the camera frame
  4. Face Matching: Compares detected face with registered students
  5. Match Found: If matched, attendance is marked as "Present"
  6. No Match: If not matched, error message is displayed
  7. One per Day: Each student can mark attendance once per day

Important Notes

  • Ensure good lighting conditions for better recognition
  • Face the camera directly and remove any obstructions
  • Only registered students can mark attendance
  • Attendance is marked only once per day per student
  • If face is not recognized, you will see "No Match" error
  • Contact administrator if you face persistent recognition issues
