How It Works

  1. Register Students: Capture student's face and store details in the database
  2. Mark Attendance: Student stands in front of camera for automatic recognition
  3. Automatic Matching: System matches face with registered students
  4. Record Attendance: If match found, attendance is marked automatically
  5. Error Handling: If no match found, displays "No Match" error
  6. Generate Reports: Download daily attendance in Excel format
