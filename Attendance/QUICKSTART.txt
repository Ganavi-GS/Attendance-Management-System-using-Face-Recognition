🚀 INSTALLATION (5 STEPS):

1️⃣  INSTALL MYSQL
    • Download from: https://dev.mysql.com/downloads/mysql/
    • Install and start service
    • Remember your password!

2️⃣  INSTALL PYTHON PACKAGES
    Open cmd in project folder and run:
    
    pip install -r requirements.txt
    
    ⚠️ Windows Users: If dlib fails, install Visual Studio Build Tools

3️⃣  CONFIGURE DATABASE
    Open: database.py
    Update line 13:
    
    self.password = "your_mysql_password"

4️⃣  TEST INSTALLATION (Optional)
    python check_installation.py

5️⃣  RUN THE APP
    • Double-click: run.bat
    OR
    • Run in cmd: python app.py

📱 USAGE (3 MAIN STEPS):

STEP 1: REGISTER STUDENTS
   • Click "Register Student"
   • Fill name and roll number
   • Click register button
   • Camera opens → Press SPACE to capture
   • Done! Student registered ✅

STEP 2: MARK ATTENDANCE
   • Click "Mark Attendance"
   • Click "Start Face Recognition"
   • Face the camera
   • Attendance marked automatically ✅

STEP 3: GENERATE REPORTS
   • Click "Reports"
   • Select date
   • Click "Download Daily Report"
   • Excel file downloads ✅

🆘 TROUBLESHOOTING:

❌ Camera not working?
   → Close other apps using camera
   → Grant camera permissions

❌ MySQL error?
   → Check MySQL is running
   → Verify password in database.py

❌ Face not recognized?
   → Improve lighting
   → Face camera directly
   → Try re-registering

❌ Installation errors?
   → Check Python version (3.8-3.10)
   → Install Visual Studio Build Tools
   → Run: pip install --upgrade pip
